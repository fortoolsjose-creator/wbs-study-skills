# Writing and argument: from evidence to a defensible position

Contents: paragraph pattern, slop detector, review protocol, feedback format, outline questions, executive summary, board-report structure, coaching moves.

Claude writes complete drafts on request: paragraphs, essays, reports, executive summaries, annotations, slides. Run the slop detector below on every draft before delivering it, so the text carries a visible path from each claim to a verified source.

The module's standard is evidence-based writing: each argumentative step has a visible path back to a source the reader can open. The patterns below make that path visible.

## Paragraph pattern

1. **Claim**: one sentence that answers part of the assignment question.
2. **Evidence**: a specific source with author, year and, for quotations, a page; a figure or a finding stated precisely.
3. **Reasoning**: one or two sentences saying why this evidence supports this claim in this context.
4. **Limit or counter**: what weakens the claim, who disagrees, what the evidence cannot show.
5. **Link**: how the paragraph serves the next step of the argument.

## Slop detector (checklist for any text, the student's or an AI's)

- [ ] Any sentence with a claim and no source or reasoning?
- [ ] Any source whose content cannot be matched with the sentence that cites it? Open it.
- [ ] Any definition with a term missing or changed compared with the source (conflated terms, truncated lists)?
- [ ] Any conclusion stronger than the evidence (words such as proves, always, will replace)?
- [ ] Any citation that cannot be found (author, year, title, venue)? Treat as fabricated until found.
- [ ] Any statistic without a primary source?
- [ ] Any claim sitting on a secondary source when the primary one is available?
- [ ] Does the paragraph consider an alternative explanation?
- [ ] Could the student explain every sentence aloud without notes?

## Review protocol

1. Ask for the question being answered and the claim of the paragraph.
2. Tag sentences C, E or R (`wbs/templates/claim-evidence-reasoning-worksheet.md`).
3. Run the detector. Report each hit with the sentence quoted.
4. For each citation, ask the student to open the source and tell you what it says on the point. Compare their report with the text.
5. Ask about the strongest objection to the claim.
6. Deliver the corrected version of the text with the changes listed, or the list of defects alone when the student asks for review only.

## Feedback format

```
Question answered: ...
What the paragraph claims: ...
Defects (by sentence): 1) ... 2) ...
Checks for you at the source: ...
Strongest objection to address: ...
Smallest next step: ...
(Strengths, briefly): ...
```

## Outline questions (Shape stage)

- What is your answer to the assignment question in one sentence?
- Which three or four reasons support it? Which source backs each?
- Which reading complicates it? Where does the evidence run out?
- What would change your mind?
- Which order lets a reader follow the argument without backtracking?

## Executive summary

Written last, read first, usable alone. General practice, confirm against the brief: purpose of the report and the question; the main finding; the recommendation; the two or three strongest reasons with the evidence base; key risks and limits; the decision requested. Aim for what a board member can act on after reading one page. The group stages the summary after the draft has been reviewed.

## Board-report skeleton (suggestion, confirm against the brief)

1. Executive summary.
2. Context and question: sector, competitors' announcements, what the board must decide.
3. Evidence on each dimension (environmental, social, economic) with sources.
4. Analysis: trade-offs, win-win cases, tensions that remain, and which board positions each finding supports.
5. Recommendation with conditions, risks and what would change it.
6. References.

## Coaching moves (when the student asks to learn the skill)

- Ask the student to say the argument aloud in three sentences before drafting.
- Ask for the weakest sentence in their own paragraph, then compare with Claude's list.
- Show a model paragraph on an unrelated topic (for example, the cafe trial evening) when the student needs to see the pattern.
- Use UK spelling and the referencing style from the brief.
